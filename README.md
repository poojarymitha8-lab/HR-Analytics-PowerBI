# HR Analytics Dashboard

## Project Overview
This project analyzes employee data to understand workforce
distribution, employee demographics, salary patterns and attrition.

##Objectives
- Analyze total employees
- Analyze employees by department
- Understand gender distribution
- Analyze employee attrition
- Calculate average employee age
- Analyze average monthly income
- Create an interactive HR dashboard

##Tools Used
- Microsoft Excel
- Power Query
- Power BI
- SQL

##Data Cleaning
The dataset was cleaned by:
- Removing duplicate records
- Handling missing values
- Checking inconsistent data
- Formatting columns
- Validating data types

##Dashboard
![HR Analytics Dashboard](Dashboard/HR_Analytics_Dashboard.png)

##Key Insights
- Engineering has the highest number of employees.
- The dashboard shows the distribution of employees by gender.
- Employee attrition can be compared across departments.
- Average monthly income varies across departments.
- Average employee age is approximately 32 years.

##Project Structure
- Dataset – Original HR dataset
- Excel – Cleaned dataset
- PowerBI – Power BI dashboard
- Dashboard – Dashboard preview
- SQL – SQL analysis queries
